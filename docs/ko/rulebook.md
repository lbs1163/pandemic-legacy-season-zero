# 팬데믹 레거시 시즌 0 룰북 노트

> 덱 카운터 보조 앱을 위해 한국어 룰북 PDF를 바탕으로 만든 Markdown 참조 초안입니다. PDF 추출 품질 한계로 핵심 덱 관련 섹션 위주로 정리했으며, 플레이 전 공식 룰북과 대조해 주세요.

## 준비 {#setup}

- 사용 가능한 도시 카드와 이벤트 카드로 플레이어 덱을 만듭니다.
- 플레이어 수에 따라 시작 손패를 나눕니다.
- 남은 플레이어 덱을 비슷한 크기의 5개 더미로 나누고, 각 더미에 악화 카드를 1장씩 섞은 뒤 하나의 플레이어 덱으로 쌓습니다.
- 위협 덱과 버린 위협 카드 구획을 준비합니다.

## 플레이어 차례 {#player-turn}

플레이어 차례에는 행동, 플레이어 카드 뽑기, 위협 카드 뽑기가 포함됩니다. 이 앱은 보드 상태 전체가 아니라 카드 이동과 위험도 표시에 집중합니다.

## 플레이어 덱 {#player-deck}

- 플레이어는 보통 차례 끝에 플레이어 카드 2장을 뽑습니다.
- 악화가 아닌 플레이어 카드는 뽑힘, 버림, 제거, 공개 손패 기록을 통해 알려진 상태가 될 수 있습니다.
- 앱은 알 수 없는 플레이어 덱 카드의 정체나 순서를 임의로 추론하지 않습니다.

## 악화 카드 {#escalation-cards}

악화 카드가 뽑히면:

1. 현재 적용 중인 규칙에 따라 증가 단계를 처리합니다.
2. 위협 덱 맨 아래에서 필요한 위협 카드를 뽑아 버린 위협 카드 구획에 놓습니다.
3. 버린 위협 카드 구획을 섞어 위협 덱 맨 위에 올립니다.
4. 뽑힌 악화 카드를 해결/제거하고 다음 플레이어 덱 더미 추적을 계속합니다.

## 위협 카드 {#threat-cards}

- 위협 카드는 별도 규칙이 없다면 위협 덱에서 뽑아 버린 위협 카드 구획에 놓습니다.
- 악화 후에는 방금 섞어 올린 버린 위협 카드 구획의 카드들이 위협 덱 맨 위의 위험 카드 묶음이 됩니다. 사용자가 순서를 기록한 경우에만 앱이 순서를 표시합니다.
- 플레이어가 명시적으로 기록하지 않은 순서는 알 수 없는 상태로 유지합니다.

## 사건 {#incidents}

일부 효과는 위협 덱 맨 아래에서 위협 카드를 뽑아 버린 위협 카드 구획이 아닌 게임 종료 구획에 놓습니다. 이 카드는 게임 중 분리해서 추적해야 합니다.

## 게임 종료 {#game-end}

게임은 성공/실패 조건에 따라 끝납니다. 덱 카운터는 종료 시점의 상태를 복기할 수 있도록 보존합니다.

## 게임 후 정리 {#after-the-game}

게임 후 정리 단계에서 게임 종료 구획의 카드는 별도 레거시 규칙이 없다면 버린 위협 카드 구획으로 이동합니다. 캠페인 중 추가된 규칙은 `legacy-rules.md`와 구조화된 룰 토글에 함께 반영합니다.
