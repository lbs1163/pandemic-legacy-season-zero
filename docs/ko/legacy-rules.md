# 레거시 추가 규칙

플레이 중 새로 공개되는 한국어 캠페인 규칙을 이 파일에 기록합니다. 앱 동작에 영향을 주는 규칙은 `src/data/rules/legacyRules.ts`의 구조화된 토글과 함께 추가해야 합니다.

## 감염 카드 {#infection-cards}

- 규칙 id: `legacy-infection-cards`
- 공개 시점: 2월 종료 후 / 레거시 규칙 B, Y
- 기본 활성화: 예
- 영향 범위: threat-deck | ui
- 내용:
  - 게임 준비 단계 B의 5번째 단계에서, 도시 이름이 적힌 감염 카드를 모두 `버린 위협 카드` 구획에 앞면이 보이게 놓습니다.
  - 2월 종료 시 첫 번째 미션 `소련 1차 시험 저지`에서 3개 시험 대상 도시 각각의 성공/실패를 기록합니다.
  - 시험 저지에 실패한 도시마다 해당 도시의 감염 카드가 캠페인에 추가됩니다.
  - 감염 카드는 위협 카드와 달리 처음에는 `버린 위협 카드` 구획에 있으므로, 첫 악화 카드가 나와 버림 구획이 섞이기 전에는 위협 덱에서 뽑히지 않습니다.
  - 한 번 섞인 뒤에는 감염 카드와 위협 카드를 구분하지 않고 같은 위협 덱 흐름에서 처리합니다.
  - 위협 카드 공개 단계 Y의 5번째 단계에서 감염 카드를 뽑은 경우, 해당 도시에 질병 큐브 1개를 놓습니다. 이 앱은 덱만 추적하므로 큐브 개수는 저장하지 않고 안내만 표시합니다.
